Anatomía de hola-mundo-php

El mismo resultado, ocho veces: "Hola, mundo!" impreso con ocho mecanismos distintos del lenguaje. Cada bloque de código, con su explicación al lado.

En resumen

El archivo no hace nada nuevo entre una forma y otra — siempre termina imprimiendo "Hola, mundo!" — pero cambia el camino: echo, print, una variable, concatenación, una función, la sintaxis corta <?= ?> y heredoc.

Formas 1–5 — variaciones de echo y print

líneas 2–4echo "Hola, mundo!";

echo es la instrucción más común para enviar texto a la pantalla. Acepta directamente una cadena entre comillas — la forma que casi todo el mundo aprende primero.

líneas 6–8print "Hola, mundo!";

print hace lo mismo que echo, pero solo admite un único valor a la vez (a diferencia de la Forma 5). En la práctica, el resultado es idéntico.

líneas 10–13$mensaje = "..."; echo $mensaje;

El texto se guarda primero en una variable ($mensaje) y luego se imprime esa variable. Es el patrón más común cuando el texto se arma o se reutiliza más de una vez.

líneas 15–17echo "Hola" . ", " . "mundo" . "!";

El punto (.) es el operador de concatenación de PHP: une varios textos en uno solo antes de imprimirlos.

líneas 19–21echo "Hola", ", ", "mundo", "!";

echo puede recibir varios argumentos separados por comas y los imprime uno tras otro, sin necesidad de concatenarlos con el punto.

Formas 6–8 — funciones y sintaxis especiales

líneas 23–28function saludar() { return "..."; }

El texto se produce dentro de una función (saludar()) que lo devuelve con return. Fuera de la función, se imprime el resultado de llamarla — la base para reutilizar lógica en vez de repetir código.

líneas 30–33<?= "Hola, mundo!" ?>

<?= ... ?> es un atajo que equivale a escribir <?php echo ...; ?>. Es muy común mezclado dentro de HTML, porque evita escribir la palabra echo cada vez.

líneas 35–39echo <<<TEXTO ... TEXTO;

heredoc permite escribir texto de varias líneas sin comillas y, a diferencia de las comillas simples, interpola variables directamente dentro del texto — aquí, $nombre.

Dato relacionado

El comentario de la Forma 7 evita a propósito escribir el símbolo ?> como texto literal. PHP lo interpreta como cierre real del bloque incluso dentro de un comentario de una línea (//) — ese fue justamente el bug que rompió una versión anterior de este mismo archivo.
