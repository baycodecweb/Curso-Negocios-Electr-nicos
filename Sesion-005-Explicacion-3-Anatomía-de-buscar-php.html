Anatomía de buscar.php

Diecisiete líneas hacen todo el trabajo: conectar, leer lo que escribió el usuario, armar una consulta segura y mostrar el resultado. Aquí está cada una, explicada por separado.

En resumen

El script conecta a escuela_mascotas, toma el texto del formulario, lo limpia y arma una búsqueda con LIKE que encuentra mascotas cuyo nombre contenga ese texto en cualquier parte — incluida la búsqueda vacía, que trae todas.

Conexión y entrada del usuario

línea 1<?php

Abre el bloque de código PHP. Todo lo que sigue, hasta el próximo ?>, se ejecuta en el servidor antes de enviarse al navegador.

línea 2mysqli_connect(...)

Abre la conexión con el servidor MySQL: usuario root, contraseña baycodec, base de datos escuela_mascotas. El resultado se guarda en $conexion y se reutiliza en cada consulta de la página.

línea 3$buscar = $_GET["buscar"] ?? "";

Lee el parámetro buscar de la URL (por ejemplo ?buscar=fir). El operador ?? dice "si no existe, usa una cadena vacía" — evita un aviso de índice indefinido la primera vez que se abre la página, antes de escribir nada.

Preparar y ejecutar la consulta

línea 4mysqli_real_escape_string(...)

Neutraliza los caracteres especiales (como comillas) del texto que escribió el usuario, para que no puedan alterar la estructura de la consulta SQL. Es la defensa mínima contra inyección SQL.

línea 5mysqli_query(... LIKE '%...%' ...)

Ejecuta la búsqueda: trae las filas de mascotas cuyo nombre contiene el texto buscado, en cualquier posición (los % son comodines). Si $buscar_escapado está vacío, LIKE '%%' coincide con todo — por eso se ven todas las mascotas cuando el campo está vacío.

línea 6?>

Cierra el bloque PHP para poder escribir HTML directamente, sin usar echo.

El formulario de búsqueda

línea 8<form method="get">

El formulario envía sus datos por GET: el término buscado queda visible en la URL, así que la búsqueda se puede recargar o compartir sin perderse.

línea 9<input name="buscar">

El campo de texto. El atributo name="buscar" es la clave exacta con la que luego se lee $_GET["buscar"] — si el nombre no coincidiera, la búsqueda no llegaría a PHP.

línea 10<button type="submit">

Botón que envía el formulario al hacer clic, o al presionar Enter dentro del campo de texto.

línea 11</form>

Cierra el formulario.

Mostrar los resultados

línea 13<?php

Vuelve al modo PHP para procesar y mostrar los resultados de la consulta.

línea 14while ($fila = mysqli_fetch_assoc($resultado)) {

Recorre el resultado fila por fila. mysqli_fetch_assoc() devuelve un array asociativo con la fila actual, o false cuando ya no quedan más — y ahí el bucle se detiene.

línea 15echo $fila["nombre"] . " - " . ...

Imprime cada mascota encontrada: nombre, tipo y edad, unidos con el operador de concatenación (.), seguidos de un salto de línea HTML (<br>).

línea 16}

Cierra el bucle while.

línea 17?>

Cierra el bloque PHP final del archivo.

Dato relacionado

PHP interpreta ?> como cierre real del código incluso dentro de un comentario de una sola línea (//). Escribirlo dentro de un comentario corta el script a la mitad — por eso conviene evitarlo incluso en texto explicativo.
