Demo: El Plano Maestro de la Memoria (DER)

Sesión 3 — Negocios y Empresas Digitales (B2B, B2C, C2C)

Esta demo no usa una base de datos real (eso llega en la Sesión 7, con la pasarela de pago). Simula, en el navegador, las 5 tablas relacionadas descritas en Codigo/db-modelo.js: clientes, productos (reutilizados de la Sesión 2), pedidos, detallePedido y pagos.

1. Diagrama Entidad-Relación

erDiagram
    CLIENTE ||--o{ PEDIDO : realiza
    PEDIDO ||--|{ DETALLE_PEDIDO : contiene
    PRODUCTO ||--o{ DETALLE_PEDIDO : "aparece en"
    PEDIDO ||--|| PAGO : genera

    CLIENTE {
        int id PK
        string nombre
        string tipo "B2B o B2C"
        string empresa
        string ruc
        string email
        string telefono
    }
    PRODUCTO {
        string id PK
        string categoria
        string nombre
        float precioReferencialPEN
    }
    PEDIDO {
        int id PK
        int clienteId FK
        string fecha
        string estado "Pendiente / Pagado"
        float total
    }
    DETALLE_PEDIDO {
        int id PK
        int pedidoId FK
        string productoId FK
        int cantidad
        float precioUnitario
        float subtotal
    }
    PAGO {
        int id PK
        int pedidoId FK
        string metodo "definido en Sesión 7"
        float monto
        string estado "Pendiente / Pagado"
        string fecha
    }
