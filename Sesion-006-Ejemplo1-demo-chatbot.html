Demo: El Asistente Virtual en Acción

Sesión 6 — Herramientas, Análisis de Mercado y Chatbots con IA

Este asistente no usa una API de IA de pago (un alumno no tiene, al hacer esta prueba de concepto, una clave de OpenAI/Anthropic ni presupuesto para usarla). Usa una técnica real de NLP — coincidencia de palabras clave sobre una base de conocimiento (FAQ + catálogo) — implementada en Codigo/motor-chatbot.js. A la derecha puedes ver, de forma transparente, con qué respuesta comparó tu pregunta y cuántas palabras coincidieron.
