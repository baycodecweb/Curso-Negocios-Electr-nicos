Anatomía de conexion.php

Cinco líneas: abrir la conexión con MySQL, comprobar si falló, y confirmar en pantalla si todo salió bien. Sin consultas todavía — eso empieza en el ejercicio 3-busqueda-php.

En resumen

El script se conecta al servidor MySQL con mysqli_connect(), detiene todo con die() si la conexión falla, y si no falló, imprime "Conexión exitosa". Nada más — este archivo solo prueba que la conexión funciona.

conexion.php
1<?php
2$conexion = mysqli_connect("localhost", "root", "baycodec", "escuela_mascotas");
3if (!$conexion) die("Error: " . mysqli_connect_error());
4
5echo "Conexión exitosa";

Conectar y verificar

línea 1<?php

Abre el bloque de código PHP. Todo lo que sigue se ejecuta en el servidor antes de enviarse al navegador.

línea 2mysqli_connect(...)

Intenta abrir la conexión con el servidor MySQL: usuario root, contraseña baycodec, base de datos escuela_mascotas. Si funciona, devuelve un identificador de conexión; si falla, devuelve false. Cualquiera de los dos se guarda en $conexion.

línea 3if (!$conexion) die(...)

Comprueba el resultado: !$conexion es verdadero solo si la conexión falló (o sea, $conexion es false). En ese caso, die() detiene el script en el acto e imprime el motivo real del error que reporta MySQL con mysqli_connect_error().

Confirmar en pantalla

línea 5echo "Conexión exitosa";

Si el script llega hasta aquí es porque la línea 3 no detuvo nada — la conexión funcionó. Este mensaje es la única confirmación visual de que todo salió bien.

Dato relacionado

El usuario y la contraseña de MySQL están escritos directamente en el código ("root", "baycodec"). Está bien para practicar en local, pero en un proyecto real esas credenciales se guardan aparte — por ejemplo en variables de entorno — para no dejarlas expuestas en el código fuente.
